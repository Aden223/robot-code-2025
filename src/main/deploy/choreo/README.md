# Choreo paths

Save the Choreo project (`.chor`) and trajectories (`.traj`) here with the Choreo 2027 alpha app
(https://choreo.autos). Set the robot config in Choreo to match the real robot (mass, MOI, bumper
size, wheel radius, gearing, Kraken X60 motors) so the generated paths are actually drivable.

Trajectory names are used in `first/robot/autos/AutoRoutines.java`, e.g. `routine.trajectory("ExamplePath")`.
