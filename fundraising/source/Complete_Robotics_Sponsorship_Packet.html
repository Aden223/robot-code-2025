How we build

Students design every part of the robot in CAD and write all of the code in Java. Mentors advise; students do the work.

Last season we had no machine shop, so every custom part was 3D-printed. The robot ran a swerve drivetrain, where each wheel steers on its own, driven by Kraken brushless motors.

What's next

A CNC router is the biggest upgrade we can make. It lets students cut aluminum and polycarbonate parts that are stronger and more precise than printed plastic. It also teaches the same design-to-machine process used in shops across Saginaw County.
